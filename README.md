# xflare — Development Studio Portfolio

Portfolio website for **xflare**, an independent development studio creating websites, digital products and automation.

## Stack

- Astro
- Tailwind CSS
- TypeScript

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The static production output is generated in `dist/`.
